## Содержимое

- `main.py` — весь конвейер: проверка 150 WAV, графики, анализ шума, полосовой фильтр Баттерворта 200–2200 Гц, SNR до и после.
- `requirements.txt` — зависимости для `main.py`.
- `download_dataset.py` — служебный загрузчик датасета из методических материалов (не часть решения).
- `index.html` — страница отчёта: графики и аудио «до/после» встроены в файл.
- `ВЫВОДЫ.md` — выводы по этапам.

## Как работает main.py

1. **Проверка датасета.** Читает все WAV из `dataset/clean` и `dataset/noisy/street/*dB`, для каждого считает длительность, частоту дискретизации, число каналов, разрядность, минимум и максимум амплитуды, пик и RMS. Проверяет, что у каждой шумной записи есть чистая пара с тем же идентификатором sp01–sp30.
2. **Выравнивание пар.** Для каждой пары «чистая — шумная» находит сдвиг по максимуму взаимной корреляции и обрезает сигналы до общей длины.
3. **Графики.** Для фраз sp01, sp12, sp25 строит осциллограммы, спектры FFT и спектрограммы чистой записи и четырёх уровней шума в общих шкалах.
4. **Анализ шума.** Оценивает шум как разность шумной и чистой записи, считает SNR для всех 120 записей, среднюю PSD речи и шума и доли мощности по полосам частот.
5. **Фильтрация.** Применяет полосовой фильтр Баттерворта 2-го порядка с полосой 200–2200 Гц (`scipy.signal.butter` + `sosfiltfilt`, нулевой фазовый сдвиг) к 12 выбранным записям и сохраняет их в `results/processed/`.
6. **Оценка.** Считает SNR до и после, ΔSNR, проверяет клиппинг, строит спектры «до/после». Дополнительно проверяет другие границы полосы и считает ΔSNR того же фильтра на всех 120 записях.
7. **Сводка.** Записывает таблицы CSV и текстовую сводку `summary.txt`.

Параметры (тип шума, выбранные фразы, порядок и полоса фильтра) заданы константами в начале файла.

## Запуск

```
pip install -r requirements.txt
python download_dataset.py
python main.py
```

Результаты появятся в `results/`: `files_table.csv` (150 строк), `experiments.csv` (24 строки), `plots/`, `processed/` (12 WAV), `summary.txt`.

Папки `dataset/` и `results/` в репозиторий не входят и создаются скриптами.
